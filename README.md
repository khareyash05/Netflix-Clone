This is a netflix clone (only frontend) using ReactJS

## Features

*   **Dynamic Content Display:** Fetches and displays a variety of movies and TV shows.
*   **Genre-based Browsing:** Allows users to explore content categorized by genre.
*   **Detailed Views:** Provides comprehensive information for each title, including synopsis and cast.
*   **Responsive Design:** Optimized for seamless viewing across different devices and screen sizes.

# Getting Started with Create React App
