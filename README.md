This is a netflix clone (only frontend) using ReactJS

## Project Overview

This project is a front-end replica of Netflix, built with ReactJS. It aims to demonstrate key UI/UX aspects of a streaming platform.

### Features

-   **Movie and TV Show Browsing**: Displaying various categories of movies and TV shows, similar to Netflix's home screen.
-   **Search Functionality**: Users can search for specific titles.
-   **Detailed View**: Clicking on a movie/show provides more details (e.g., description, rating, cast).
-   **Trailer Playback**: Integration with YouTube for playing trailers (if applicable).
-   **Responsive Design**: Optimized for various screen sizes.
