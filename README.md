This is a netflix clone (only frontend) using ReactJS

## Features

*   **Browse Content:** Display a wide range of movies and TV shows organized into categories (e.g., Trending Now, Netflix Originals).
*   **Hero Banner:** A dynamic main banner showcasing a featured title with a description and action buttons.
*   **Responsive Design:** Optimized for seamless viewing across various devices and screen sizes.
