This is a netflix clone (only frontend) using ReactJS

## Project Overview

This project is a frontend-only implementation mimicking the user interface of Netflix. Key features include:

*   **Dynamic Content Display:** Showcases various categories of movies and TV shows, such as Netflix Originals, Trending Now, Top Rated, Action Movies, Comedy Movies, Horror Movies, Romance Movies, and Documentaries.
*   **Hero Section:** A prominent banner displaying a featured movie or TV show, complete with its title, overview, and action buttons.
*   **Movie/TV Show Rows:** Horizontally scrollable carousels for browsing titles within different categories.
*   **Detailed View:** Upon clicking a movie or TV show
