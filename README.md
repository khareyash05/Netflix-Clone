This is a netflix clone (only frontend) using ReactJS

## Features

*   **Browse Content:** Explore a vast library of movies and TV shows organized into various categories.
*   **Detailed Views:** Click on titles to view detailed information, including descriptions, genres, and more.
*   **Search Functionality:** Easily find specific movies or shows using the integrated search bar.
*   **Responsive Design:** Enjoy a seamless viewing experience across different devices and screen sizes.
*   **Netflix-inspired UI:** A clean and intuitive user interface mimicking the look and feel of Netflix.
