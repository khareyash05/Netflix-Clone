This is a netflix clone (only frontend) using ReactJS

## Project Features

*   **Browse Content:** Display a list of movies/TV shows, categorized or in carousels.
*   **Play Trailer/Video:** Basic video playback functionality (e.g., embedding YouTube trailers).
*   **Responsive Design:** Optimized for various screen sizes.
*   **User Interface:** Mimics the look and feel of Netflix's UI.
